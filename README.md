# 룸테트리스 (RoomTetris) 📐🛏️

> **"원룸 가구 구매 실패 방지! 1인 가구 생존형 가구배치 & mm 수치 가이드 PWA"**  
> 감성 인테리어는 사치! 문 열리는 반경(800mm), 창문 채광, 콘센트 간섭을 철저히 계산하여 동선이 꼬이지 않는 3대 생존 가구 배치와 기성 가구 한계 치수(mm)를 제공합니다.

---

## ✨ 핵심 기능

1. **공간 구조 분석 (Photo Scan & Templates)**
   - 사진 업로드 시 창문, 방문, 콘센트 간섭 유추
   - 4~5평 원룸, 7평 오피스텔, 9평 1.5룸, 12평 빌라 안방 템플릿 기본 탑재
2. **룸테트리스 3대 생존 배치안**
   - **옵션 A: [휴식 집중형 배치]**: 수면의 질과 독립성 최우선
   - **옵션 B: [작업/재택근무 집중형 배치]**: 모니터 역광 방지 및 업무 동선 확보
   - **옵션 C: [수납 극대화형 배치]**: 수납침대 + 틈새장으로 데드스페이스 제로
3. **2D 인터랙티브 평면도 (Top-View Blueprint)**
   - 방 사각형 위에 침대, 책상, 옷장 블록 및 800mm 문 개폐 위험 반경 실시간 렌더링
4. **가구 구매 실패 방지 가이드 (수치 팩트체크)**
   - 침대 (SS 1100x2000 vs Q 1500x2000) 한계 명시
   - 책상 (1200x600 마지노선) 규격 안내
   - 걸레받이 몰딩(15mm) 및 보행 통로(600mm) 사수 팁
5. **PWA 모바일 웹앱 지원**
   - 1초 만에 스마트폰 홈 화면에 설치하여 가구 쇼핑 시 바로 확인 가능
